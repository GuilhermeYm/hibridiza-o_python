<h1>Hibridização</h1>
Você poderá inserir a sua molécula orgânica, seguindo o padrão SMILES dentro do parâmetro da chamada da função principal. Logo depois, o programa irá gerar uma página HTML com a molécula, já representada. Se você quiser fazer um quis sobre as hibridizações dos átomos de carbono, basta responder a última pergunta. 

Eu fiz esse programa só para diversão, mas se quiser testar fique à vontade.
